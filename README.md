### 📂 Estrutura do Repositório

Cada pasta de projeto neste repositório segue uma organização padrão para facilitar a leitura e avaliação:

* `Dataset/` ou `Dados/`: Arquivos brutos utilizados (Excel, CSV, bases públicas).
* `Dashboard/`: Arquivos `.pbix` com os relatórios prontos.
* `Imagens/`: Capturas de tela dos dashboards para visualização rápida no README de cada projeto.
